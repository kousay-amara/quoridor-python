# Sample Load Files

Use these files to test `load` manually from the CLI.

Examples:
- `load sample_saves/basic.txt`
- `load sample_saves/blitz.txt`
- `load sample_saves/comments.txt`
- `load sample_saves/four_players_blitz_timeout.txt`

Files:
- `basic.txt`: initial 2-player game, no blitz.
- `blitz.txt`: current save format with blitz in `[settings]`.
- `comments.txt`: save with inline and block comments.
- `contest_example.txt`: minimal contest-mode example.
- `four_players_blitz_timeout.txt`: 4-player blitz save with walls, one timeout, and player 1 one move away from victory.
